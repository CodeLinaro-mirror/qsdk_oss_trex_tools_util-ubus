timer_delay : delay n second to execute action ( such as shutdown )
shutdown : set 1 to exit program after timer_delay
ifname : device name for set_igmp_route.sh
trap_mode : trap mode value for set_igmp_route.sh
fake_mode : fake mode value for set_igmp_route.sh
script_name : script file name, default : "set_igmp_route.sh"
dbg_level : enable/disable debug message (1 : enable, 0: disable)
cfg_reload : reload ubus_event rule file (1 : reload)
cfg_dump : print current rule setting (1 : dump rule)

* How to setup variable value :
util_ubus_event_ctl --> for util_ubus_event parameter setting 
ubus send util_ubus_event_ctl '{"set_delay":5,"shutdown":1}'	--> Exit program after 5 second
ubus send util_ubus_event_ctl "{\"ifname\":\"eth4\",\"trap_mode\":1,\"fake_mode\":0}"  --> set ifname,trap_mode,fake_mode
ubus send util_ubus_event_ctl "{\"script\":\"/usr/bin/set_igmp_route.sh\"}"
ubus send util_ubus_event_ctl '{"cfg_reload":1}'
ubus send util_ubus_event_ctl '{"cfg_dump":1}'

* How to turn on debug message :
UTIL_DBG=1 util_ubus_event &
or
ubus send util_ubus_event_ctl '{"dbg_level":1}'

* What event monitor by program:
Please ref. util_event_rule.txt

* What action with network.interface event:
{ "network.interface": {"action":"ifup","interface":"lan"} }  -->  run script "set_igmp_route.sh" when event is detected

* How to send user event:
ubus send util_ubus_event "{\"action\":\"test\"}"
